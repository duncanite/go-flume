# go-flume

A Go module for the Flume 2 water monitor. Nothing is built yet.

[docs/design.md](docs/design.md) is the research it starts from: what the device offers,
the ways into it (Flume's REST API in the cloud, the bridge's MQTT traffic, the radio), how
little of it fits Matter, and what a module here could be, with no choice made.
